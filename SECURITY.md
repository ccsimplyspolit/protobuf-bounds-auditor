# Security Policy & Coordinated Disclosure

## Scope & Defensive Usage
`protobuf-bounds-auditor` is a static schema analyzer and `libprotobuf-mutator` (`DEFINE_PROTO_FUZZER`) harness generator designed for defensive code auditing and pre-deployment input validation testing.

## Reporting a Vulnerability
If you discover a security issue or parser bug in `protobuf-bounds-auditor`, please report it privately via GitHub Private Vulnerability Reporting or by emailing `cc.simply.spolit@gmail.com`.
